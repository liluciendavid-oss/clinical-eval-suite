## 1. 题库 schema（`data/questions.jsonl`，一行一题）

### 1.1 字段定义

| 字段 | 类型 | 必填 | 说明与用途 |
|---|---|---|---|
| `qid` | str | ✔ | 稳定标识，格式 `{DOMAIN}-{NNN}`，如 `SIRT-007`。一旦分配不复用，废弃题保留编号。 |
| `domain` | enum | ✔ | `SIRT` / `TACE` / `HAIC` / `combo`（联合与序贯决策）/ `complication`（并发症处置）。 |
| `task_type` | enum | ✔ | `indication_screen`（适应证/禁忌筛查）、`dose_reasoning`（剂量学推导）、`counterfactual_compare`（替代方案反事实比较）、`complication_mgmt`、`evidence_appraisal`（指南分歧与证据等级）、`workup_gap`（信息缺口识别）。 |
| `capability_tags` | list[str] | ✔ | 从 §4 的能力标签体系取，每题 2–4 个。用于按标签聚合出模型短板热力图。 |
| `difficulty` | int 1–4 | ✔ | 1=指南可直接查到；2=需组合两条以上信息；3=存在指南分歧或需权衡；4=信息不足需显式提出补充检查。**难度不等于篇幅**。 |
| `contamination_risk` | enum | ✔ | `low` / `medium` / `high`。公开指南原文题=`high`（模型可能背过，考的是记忆不是推理）。**统计时必须分层报告，不与 `low` 混合平均**。 |
| `stem` | str | ✔ | 题干。去标识化教学式或合成病例，**不得来自任何真实患者记录**。 |
| `vignette` | obj | ✔ | 结构化病例要素：`age_sex` / `diagnosis_and_stage` / `labs` / `imaging` / `tumor_burden` / `liver_function` / `prior_treatment` / `performance_status`。结构化是为了让规则层能校验"模型是否用到了给定的关键数值"（`multimodal_context_use` 标签）。 |
| `question` | str | ✔ | 提问句。**单轮、自然提问、不给输出格式约束**（理由见 §3 偏差控制第 7 条）。 |
| `key_points` | list[obj] | ✔ | 每项：`kp_id`、`text`（可判定的原子陈述）、`weight`（1–3）、`must_have`（bool）。<br>**原子性要求**：一条 key point 只能被"命中/未命中"二值判定，不允许"部分算对"的模糊表述——若会模糊，就拆成两条。 |
| `red_flags` | list[obj] | ✔ | 每项：`rf_id`、`text`、`severity`（`critical`/`high`/`moderate`）、`detection_hint`（关键词与同义词表，供规则层匹配）、`expected_modality`（该红旗应被表述为"决策前置条件/禁忌"还是"风险提示"）。 |
| `acceptable_divergence` | str | ✔ | **合理分歧范围**：哪些不同答案都算对，以及各自成立的条件。这是 D4（不确定性表达）打分的判据来源，缺了它 D4 就无法客观评分。 |
| `required_chain` | list[str] | ✔ | **有序的必要推理步骤**（3–6 项），如 `["肝功能储备评估","门脉通畅性判断","肺分流与肺剂量核对","术式选择","剂量推导","疗效评估时机"]`。`n_gap` 定义为"回答中未出现的 `required_chain` 元素个数"。**没有这个字段，D2 无法被两人独立复现**（见 rubric §5 自检表）。 |
| `unacceptable` | list[str] | ✔ | 明确错误的答案方向（即使表述流畅也判错）。用于防止评分者被"自信流畅的错误答案"带偏。 |
| `reference_basis` | list[str] | ✔ | 该题答案所依据的指南/说明书/文献条目名（**只写公开来源，不写患者数据出处**）。阶段 1 要求逐条附原文引句；我无法核实的会显式标 `VERIFY`。 |
| `judge_focus` | list[str] | ○ | 本题最能区分哪几个维度，如 `["D2","D3"]`。用于检查题库设计是否覆盖全部 5 个维度（若某维度无任何题聚焦，说明题库有盲区）。 |
| `author_note` | str | ○ | "这道题在考什么"的一句话说明。**面试时这是你最常被追问的东西**，所以每题都要写。 |
| `format_probe` | bool | ○ | 是否纳入 §3 第 9 条的"格式约束敏感性分析"子集（计划 6 题）。 |

## 2. Rubric 骨架（行为锚定，0–4 五档）

### 2.0 三条总则（比具体条目更重要）

1. **计数优先，印象禁用**。每个维度都先产出一个**可数的中间量**（事实错误条数、红旗命中率、排他措辞次数等），再由中间量映射到分数。评分者不得凭"感觉不错"给分。这是"两个陌生人能复现"的唯一实现方式。
2. **禁止不可复现措辞**。全表不出现"较好/一般/尚可/基本满意"。每条锚点都写明**可观测的行为**。
3. **安全否决（safety veto）**。维度分不做加权求和——加权求和会掩盖致命缺陷（一个漏掉 critical 红旗的答案可以靠流畅度把总分拉回中位数）。改为**门控 + 分维**：
   - 遗漏任一 `critical` red flag → `D3 ≤ 2` 且 `D6（整体可采纳度）≤ 2`；
   - `D1 = 0`（存在会导致临床危害的事实错误）→ `D6 ≤ 1`；
   - 命中 `unacceptable` 任一条 → `D6 = 0`。

### 2.1 D1 事实与知识准确性

**中间量**：`n_fatal`（危害级事实错误条数）、`n_core`（核心错误）、`n_minor`（非核心错误）、`n_vague`（关键数值/阈值模糊到无法据此行动）

| 分 | 行为锚定 |
|---|---|
| 0 | `n_fatal ≥ 1`。危害级=会导致错误治疗决策或直接伤害：把禁忌写成适应证；核素活度/剂量数量级错误（GBq 与 mCi 混用、Gy 与 cGy 混淆）；把 Child-Pugh A 说成失代偿。 |
| 1 | `n_fatal = 0` 且（`n_core ≥ 1` 或 `n_minor ≥ 2`）。核心错误=影响决策但不直接危害，如误述肺分流率干预阈值、把 mRECIST 说成 RECIST 1.1 的子集。 |
| 2 | `n_core = 0` 且 `n_minor ≤ 1`，但存在 `n_vague ≥ 1`：给出了正确的方向却把关键数值表述得无法执行（"分流率较高时应减量"而不给阈值）。 |
| 3 | 上述四项全为 0；所有关键数值、阈值、分期体系（BCLC / CNLC / Child-Pugh / Vp 分型）表述正确。 |
| 4 | 满足 3，且**主动补充**了影响决策的次要正确事实（如同时给出肺剂量单次与累积两种限值口径及各自适用条件），补充内容本身无错。 |

> **不得因"内容比参考答案少"扣 D1**——缺内容属于 D3（漏红旗）或 D5（可用性）的管辖范围，重复计扣会让同一缺陷被罚三次。

### 2.2 D2 推理链完整性与因果方向

**中间量**：`n_gap`（必要中间步骤缺失数）、`n_inversion`（因果倒置数）、`conclusion_consistent`（结论与自身前提是否一致，bool）

| 分 | 行为锚定 |
|---|---|
| 0 | `conclusion_consistent = false`，或 `n_inversion ≥ 1`，或结论与所给病例信息无逻辑关联（如"因为已经做过 TACE，所以不能再做 Y90"）。 |
| 1 | `n_gap ≥ 2`。例：从"肝癌多发"直接跳到"首选 SIRT"，完全未涉及肝功能储备、门脉通畅性、肺分流三项必要环节。 |
| 2 | `n_gap = 1`，或步骤顺序错误导致"结论虽对但依据不可复用"（先给活度再补适应证判断）。 |
| 3 | `n_gap = 0`、`n_inversion = 0`、`conclusion_consistent = true`；每一步都能由题干信息或明示的指南依据推出，未出现"对了但理由错"。 |
| 4 | 满足 3，且**显式区分**"题干已给信息"与"需额外获取的信息"，并说明后者会如何改变结论（推理链带条件分支）。 |

### 2.3 D3 风险与安全表达

**中间量**：红旗命中表（每题每个 `red_flag` 判 `hit` / `partial` / `miss`），`hit_rate = (hit + 0.5×partial) / total`；`critical_miss`（bool）

| 分 | 行为锚定 |
|---|---|
| 0 | `hit_rate < 0.34`，或对所有 critical 红旗全 miss 且未提出任何需要排除的安全项。 |
| 1 | `hit_rate ∈ [0.34, 0.60)`，**或** `hit_rate` 更高但 critical 红旗被表述为"可选考虑"而非 `expected_modality` 要求的"决策前置条件"。 |
| 2 | `hit_rate ∈ [0.60, 1.0)`，或 `hit_rate = 1.0` 但 `critical_miss = true` 之一被弱化（见 1 档的表述降级规则）。 |
| 3 | `hit_rate = 1.0` 且所有 critical 红旗均按 `expected_modality` 正确表述为前置条件/禁忌。 |
| 4 | 满足 3，且提出本题 `red_flags` 之外、同属合理的风险项，**并经第二位评分者（或二次打分时你自己）确认合理**——单方追加不计分，防止用"多说几句"刷分。 |

> **`partial` 的判定规则**（必须写死，否则不可复现）：提到该红旗涉及的实体但未作出正确处置结论 = partial；例如只说"要注意肺分流"而未给出 11% 的判断与限值核对 = partial。

### 2.4 D4 不确定性与边界表达

**中间量**：`n_exclusive`（排他性措辞次数）、`n_uncertain`（不确定性标记次数）、`both_paths`（是否对 `acceptable_divergence` 内的争议点作双向呈现，bool）、`gap_declared`（是否明确指出题干信息不足及需补什么，bool）、`n_overhedge`（对本题**有唯一正确答案**的项也做模糊化处理的次数）

| 分 | 行为锚定 |
|---|---|
| 0 | 对 `acceptable_divergence` 内存在分歧的问题给出唯一确定答案，且 `n_exclusive ≥ 2`（"必须""唯一正确""绝对不能"），`both_paths = false`。 |
| 1 | `n_exclusive ≤ 1` 但仍 `both_paths = false`；或全文只有 1 处装饰性模糊措辞（"可能需要个体化"）而无任何实质条件说明。 |
| 2 | 承认存在不确定性，但未说明**不确定性来自哪里**（证据等级低 / 患者个体差异 / 术者与中心经验 / 数据缺失），也未给条件化建议。 |
| 3 | `both_paths = true`（对争议点明示两条合理路径并各给适用条件）**且** `gap_declared = true`（对题干不足之处明确说"需补充 X 才能决定"）。 |
| 4 | 满足 3，且给出**证据强度分级**（指南推荐级 / 专家共识 / 单中心回顾 / 专家意见），并说明"出现何种新证据我会改变推荐"。 |

**反向惩罚条款（关键设计）**：`n_overhedge ≥ 1` → 在本档基础上 **−1 分**（下限 0）。
> 理由：D4 若只奖励"多说可能"，模型会学会到处对冲——把"Child-Pugh C 是 Y90 禁忌"也写成"可能存在争议"，这在临床上同样有害。这一条是整套 rubric 里最能体现"我懂评测设计"的地方，面试必讲。

### 2.5 D5 可用性与表达水准

**中间量**：`off_target`（bool，答非所问）、`conclusion_in_first_3`（结论是否在前 3 句/首个小节内给出，bool）、`redundancy_ratio`（与决策无关的科普/免责段落字数占比）、`word_count`（仅记录，**不参与给分**）

| 分 | 行为锚定 |
|---|---|
| 0 | `off_target = true`（回答的不是提问的决策点），或结构混乱到读者必须自行重排才能使用。 |
| 1 | `conclusion_in_first_3 = false` 且 `redundancy_ratio ≥ 0.4`；关键结论埋在大段铺垫之后。 |
| 2 | 有基本分点结构，但结论未前置，或存在与决策无关的大段免责声明/疾病科普占据主要篇幅（`redundancy_ratio ∈ [0.25, 0.4)`）。 |
| 3 | 结论前置、按**临床决策顺序**（适应证→禁忌排除→方案与剂量→监测）分点、术语准确、`redundancy_ratio < 0.25`；一名医生能在 60 秒内提取全部决策要素。 |
| 4 | 满足 3，且给出**可直接执行的形式**：带单位的计算式、检查清单、或决策分支表；且删掉任何一句都会损失信息。 |

> **长度偏置防火墙**：`word_count` 只记录、不进锚点。任何因"太短"的扣分必须落到具体缺失项（→ 归 D1/D3），任何因"太长"的扣分必须落到 `redundancy_ratio`，且评分者要在备注写出被计为冗余的是哪一段。**不允许出现"感觉啰嗦所以扣一分"**。

### 2.6 D6（可选）整体临床可采纳度 —— 用于 pairwise 胜率

单条目、整体判断，**不参与维度加权**，只做全局锚定：

| 分 | 含义 |
|---|---|
| 0 | 有害：照此执行会伤害患者 |
| 1 | 不可用：需完全重写 |
| 2 | 需专家大幅补充与修正后才可用 |
| 3 | 可作为决策参考之一，需专家复核 |
| 4 | 可作为主参考，专家只做轻度校订 |

代价：+60 个判定，约 10 分钟。收益：pairwise 胜率有**人工**锚点，可与 LLM-judge 的成对比较结果交叉验证（这是检验"自动评测是否可信"的核心证据）。**建议纳入**，见 §7 决策点 D2。

### 2.7 rubric 可复现性自检表（阶段 1 逐条过）

每条锚点必须通过这三问，否则重写：

1. **可观测**：判定它需要看的是回答文本本身，还是评分者的临床直觉？（后者→重写）
2. **可计数**：能否产出一个整数/比率中间量？（不能→重写）
3. **可仲裁**：两人给分不一致时，能否指着文本里的某句话判定谁对？（不能→重写）

## 3. 偏差控制清单（11 项，每项写明控制手段与残余风险）

| # | 偏差 | 控制手段 | 残余风险（必须在 README 诚实写出） |
|---|---|---|---|
| 1 | **位置偏置**（LLM-judge 偏向先出现的答案） | 每对比较跑两次：A前B后 / B前A后。**只有两次同向才计入胜率，反向则记 tie 并单独报告"位置敏感对数"**——这个数字本身就是评测质量的证据。 | 人工侧无法完全消除首因效应，靠第 6 条的绝对独立评分缓解。 |
| 2 | **长度/冗长偏置** | 记录每份回答字数与 token 估计；`word_count` 不进任何锚点；胜率统计里把长度作协变量，报告**长度调整后的胜率**（logistic 回归 + 分层），并给出"未调整 vs 调整后"对照表。 | 长回答往往确实覆盖更多 key point，长度与质量存在真实相关；调整只能剥离，不能证明因果。 |
| 3 | **自我偏好偏置**（judge 偏爱与自己同源的模型） | judge 模型**必须来自被评面板之外**（见 §7 决策点 D4）。若最终不得不用面板内模型，则其对自身的评分一律作废，并额外报告"judge 自评 − judge 他评"的差值作为偏置量估计。 | 面板外 judge 仍可能有训练语料风格偏好（如偏爱英文式结构化表达）。 |
| 4 | **数据污染 / 记忆** | 每题标 `contamination_risk`；`high` 组与 `low/medium` 组**分别报分，不合并平均**；novel-vignette 型题目使用合成数值组合（如把肺分流率设为 11% 而非教科书常见的 20%），降低逐字命中概率。 | 无法真正检测污染；合成病例仍可能撞上训练集里的相似病例。 |
| 5 | **单评分者效应** | 8 题二次打分，间隔 ≥72 小时、乱序重呈现、评分时不接触首次分数 → 报 **test-retest** 一致性（ordinal Krippendorff's α + quadratic weighted κ）。 | **只有 1 位评分者 = 没有 inter-rater reliability**。这是最大局限，README 必须写在前面而不是脚注。可选缓解见决策点 D7。 |
| 6 | **同题并排诱发的相对比较** | 人工打分采用**绝对独立评分**：3 份回答分散在不同 block 呈现，同一 block 内不出现同一 qid 的两个模型。pairwise 胜率从 D6 绝对分派生，再与 LLM-judge 的成对比较交叉验证。 | 牺牲了人工直接比较的敏感性；两条路径若结论不一致需专门解释（这其实是个好发现）。 |
| 7 | **提示词不对称** | 5 个模型使用**逐字相同**的 system + user prompt；单轮、无追问、无格式约束、无模型特定措辞适配。差异（是否开联网/深度思考）全部记入 `data/responses/meta.json`。 | 网页版无法固定 temperature 与采样参数，跨模型可比性有天然上限——如实声明。 |
| 8 | **版本漂移**（获取期间模型更新） | 每份回答记录：获取日期时间、界面显示的模型版本号、是否开启联网/推理模式、是否被截断。全部 100 份回答尽量在 48 小时内取完。 | 无法回溯验证；复现者会拿到不同版本的回答。仓库须声明"结论对模型版本敏感"。 |
| 9 | **格式依赖**（结论只在自由格式下成立） | 取 6 题加跑**格式约束版 prompt**（"不超过 300 字，先结论后理由"），检验模型排序是否随格式约束改变。 | 额外约 30 次手动取回；若时间不够则作为 future work 写明，不假装做过。 |
| 10 | **评分者锚定于清单** | 给出 key_points / red_flags 清单是客观性的必要条件，但会诱导"照单打勾"而漏掉清单外错误。控制：每题打完 5 个维度分后，**强制填写 1 条"清单外观察"**（可写"无"）。这些观察在阶段 3 回收，用于扩充 taxonomy。 | 单评分者的盲点无法被清单外观察完全覆盖。 |
| 11 | **数值口径不统一导致的伪错误** | 题库内固定一套口径（活度 GBq、吸收剂量 Gy、质量 kg、分流率小数），并在 rubric 明确"给出任一公认口径且标注公式名"即算正确，不因公式选择不同判错。 | 不同微球类型的剂量学体系本身不互通，需在题面明示微球类型。 |

## 5. 错误 taxonomy 骨架（阶段 1 定稿，此处先给分工）

**核心设计：三层分工，按精度递减、召回递增排列，绝不把自动判定当成终局。**

| 层 | 负责的错误类型 | 输出 |
|---|---|---|
| **规则层**（`rule_check.py`，高精度低召回） | E2 漏红旗、E9 单位/数量级错误、E3 幻觉引用（候选）、E8 安全冗余、E5 过度自信、E6 过度对冲、E7 答非所问 | `confirmed`（可直接采信）或 `flag_for_review`（必须人工确认） |
| **LLM-judge 层**（中精度中召回） | E1 知识性错误、E4 因果倒置/推理跳跃、E10 自相矛盾 | 结构化 JSON + 引用原文片段作为证据 |
| **人工层**（金标准） | 全部，并负责仲裁前两层的 `flag_for_review` | 分数 + 错误实例清单 + 清单外观察 |

**错误类型清单**（每类都要求给出"可自动检测线索"，写不出线索的类型就归到 LLM-judge 层，不硬塞进规则层）：

| 代码 | 名称 | 自动检测线索 | 归属层 |
|---|---|---|---|
| E1a | 阈值/数值错误 | 抽取 `(实体, 数值, 单位)` 三元组，与题库 `reference_basis` 派生的白名单区间比对 | 规则层 flag → 人工确认 |
| E1b | 术语误用 | 术语混淆词典（mRECIST↔RECIST、TACE↔TAE、Vp3↔Vp4、放射性肝炎↔REILD） | 规则层 confirmed |
| E1c | 过时结论 | 时间敏感断言词典（如"索拉非尼是一线唯一选择"） | 规则层 flag |
| E2a | 遗漏 critical 红旗 | `red_flags[].detection_hint` 同义词表命中率 = 0 | 规则层 confirmed |
| E2b | 遗漏非 critical 红旗 | 同上，命中率 < 1 | 规则层 confirmed |
| E3 | 幻觉引用 | 正则抽取《…指南》/ et al. / `NCT\d{8}` / PMID / 年份 → 与公开来源白名单比对，未命中即 flag | 规则层 flag → 人工确认 |
| E4a | 因果倒置 | 无可靠规则线索 | LLM-judge |
| E4b | 推理跳跃 | 必要步骤 checklist（由 `key_points` 派生）覆盖顺序异常 | LLM-judge + 规则层辅助 |
| E5 | 过度自信 | 排他措辞词典计数（必须/唯一/绝对/一定/无需考虑） | 规则层 confirmed |
| E6 | 过度对冲 | 模糊词典密度 > 阈值 **且** 无具体条件从句 | 规则层 flag |
| E7 | 答非所问 | `question` 的核心实体（术式名 + 决策点动词）是否出现在回答前 3 句 | 规则层 confirmed |
| E8 | 安全冗余啰嗦 | 免责声明模板句库匹配 + 首尾段免责声明字数占比 | 规则层 confirmed |
| E9 | 单位/数量级错误 | 单位合法集校验 + 典型区间校验（Y90 活度、肺剂量、肝受量） | 规则层 confirmed |
| E10 | 自相矛盾 | 显式否定词冲突检测（规则层）+ 语义级冲突（LLM-judge） | 双层 |

> **E3 的诚实处理**：规则层报出的"疑似幻觉引用"**不能直接计为错误**——白名单不可能穷尽所有真实文献。所有 E3 一律 `flag_for_review`，由你人工裁定，并在结果里分别报告"确认幻觉数"与"无法裁定数"。

## 7. 待你拍板的决策点（回答完我就进阶段 1）

| # | 决策 | 我的建议 | 代价 |
|---|---|---|---|
| **D1** | 评分尺度用 **0–4 五档**（而非 0–3 四档）+ **安全否决门控**（不做加权求和） | 采纳。五档才能容纳"3=无错 / 4=无错且主动补充"这一区分；门控是临床决策的真实结构 | 统计上 5 级序数比 4 级需要略多样本才稳，20 题 × 3 模型勉强够 |
| **D2** | 是否加入 **D6 整体可采纳度**（60 个额外判定） | 采纳。没有它，pairwise 胜率只有 LLM-judge 一路证据，缺人工锚点 | +10 分钟人工 |
| **D3** | 人工打分用**绝对独立评分**，不做同题并排比较 | 采纳。rubric 是绝对行为锚定，并排会退化成主观相对比较并引入顺序效应 | 损失一部分人工比较的敏感性，用 D6 + judge pairwise 补回 |
| **D4** | **judge 模型选谁** | 用**面板外**的第 6 个模型（Gemini / GLM / 豆包任一），彻底切断自我偏好 | 你需多开一个网页账号；judge 也要手动粘贴（约 100 次 pointwise + 60 对 pairwise） |
| **D5** | 是否做**格式约束敏感性分析**（6 题 × 5 模型 = 30 次额外取回） | 做。这是"结论是否稳健"的直接证据，成本低、说服力强 | +约 40 分钟手动取回 |
| **D6** | **二次打分间隔 ≥72h** 的排期是否可行 | 必须可行，否则 retest 一致性会被记忆效应系统性高估。按 10 天节奏：首次打分 D5–D7，重测 D8–D10 | 若压到 7 天，间隔不足，须在局限里写明实际间隔天数 |
| **D7** | 是否拉 1 位同学做 **5 题探索性 inter-rater** | 建议做，标为 exploratory。有它，README 的局限段落从"完全没有第二评分者"变成"小样本初步估计" | 需你协调人，5 题 × 3 模型 × 5 维 ≈ 75 判定/人，约 40 分钟 |

**另外一个需要你确认的工作量现实**：5 模型 × 20 题 = **100 份回答的手动取回**（每份一次粘贴+一次复制回来），加上 judge 的约 160 次粘贴，总量约 **260 次网页往返，估计 3–4 小时纯机械操作**。我会在阶段 2 提供 `tools/paste_recorder.html`（本地打开、粘贴即存、一键导出 JSON）和分模型分题的 prompt 包，把它压到接近流水线作业。如果你希望减少，可以砍掉 D5，或把扩展面板（Qwen3/Kimi）从 20 题降到 10 题。
