# 一页纸：如何将评测输出用于后续改进

本页是分析与决策框架，不是已观察到的模型结论。当前真实评分尚未冻结，R2 回表与真实 LLM-judge 结果尚缺。任何训练、产品或模型选择建议都应在证据复核后提出。

最新评分进展：原 8 项 D3 分数已由主评分者裁定，2 项由 4 改为 3，6 项保留 4；其他评分与 rubric 未变。复跑为 valid=13、review=11、soft_anchor=27，mismatch/invalid/rejected 均为 0。6 项保留 4 分的具体引文对应仍待作者选择，部分辅助备注仍待核验。5 条冗余扣分引文已接受暂缓归档，原 redundancy_ratio 与 D5=2保留，不阻塞方法与工程试点候选整理；不将暂缓视作证据已验证。

## 输出、复核与动作

| 输出 | 先核验什么 | 可以形成的下一步 |
|---|---|---|
| 分维得分与错误实例 | 分数能否追溯到原文和 rubric v1.2，差异是否由少数题驱动 | 提出针对某类能力的扩测假设，补充相关题目与人工复核 |
| 安全门控触发记录 | 是否真正遗漏 critical 红旗或命中 unacceptable，是否存在规则误报 | 将已裁定实例整理为安全回归用例；产品准入标准需另行验证 |
| 虚构题干信息实例 | 区分患者既有事实、假设条件、差值和建议补做的检查 | 建立事实引用检查用例，分析错误产生环节 |
| D4 的排他措辞与过度对冲 | 词典命中是否属于术语或合理条件表达 | 分别补充过度自信和不必要对冲的测试样例 |
| D5 真实分析（若开展） | 明示5条冗余扣分引文未归档、未独立复核，保留原始评分 | 在披露该局限的范围内分析，不声称证据审计完整；方法与工程试点候选整理可继续 |
| 规则层 confirmed 与 flag | confirmed 是否仍需语义复核；flag 是否已由人工裁定 | 优先安排复核，并以已裁定实例扩展对照集；不把原始 flag 当作训练真值 |
| D6 pairwise 胜率与 bootstrap 区间 | 题目重采样、有效配对数、区间宽度与多重比较 | 在当前题集上报告探索性差异；区间跨 0.5 表明证据不足，不代表等效 |
| 长度匹配或格式探针结果 | 有效样本是否足够、是否受格式计数和任务结构影响 | 提出长度或格式敏感性假设，再通过受控实验检验 |
| 24 份同人重测 | 配对、间隔记录、裁定前后版本是否一致 | 评估同一评分者的稳定性，定位需要重写或补充例子的锚点 |
| 第二评分者结果（未获得） | 评分者独立性、培训、样本和分歧证据 | 数据到位后探索专家间一致性；当前不能报告 |
| judge 结果（未获得） | 证据有效性、位置偏差与相对人工评分的偏差 | 数据到位后评估是否适合作为辅助预筛；当前不能宣称已验证 |

## 优先顺序

1. 继续整理方法与工程试点候选；5条冗余扣分引文暂缓，不作为该项工作的阻塞条件。6项保留D3=4的具体引文对应及辅助备注仍按原状态处理，原8项D3分数不重复裁定。
2. 生成真实分维结果和同人重测分析，明确样本、区间、未测环节及可复算范围。
3. 将经过临床裁定的安全问题和事实错误整理为回归测试候选；统计关联仅用于提出假设。
4. 扩充题目、引入独立评分者，再评估候选结论在新样本上的稳定性。

## 当前不能据此做出的判断

不能仅凭 n=20、单评分者的结果推断一个模型普遍更安全，也不能把门控前后排序变化直接归因于“模型靠排版掩盖错误”。变化提示需要进一步拆解的评分结构或样本差异。

不能把某个 α/κ 阈值、均值差或错误计数临时写成已经验证的产品准入标准。正式阈值应在分析前明确，并结合任务风险、独立复核和样本外验证决定。

作者与主评分者为同一人，AI 辅助审计不能替代独立临床评分者。即使工程验收全部通过，评测结论仍需接受这一限制。
